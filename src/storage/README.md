# src/storage

Файловое хранилище документов пользователя.

- Файлы пишутся на диск в зашифрованном виде
  (`@dr.pogodin/react-native-fs`), ключ шифрования — в Keychain/Keystore
  через `react-native-keychain`.
- По умолчанию всё локально на устройстве. Облачная синхронизация —
  только позже и только с client-side (E2E) шифрованием.
- Ключ никогда не покидает устройство и не попадает в БД, логи или
  аналитику.

## Обязательно при реализации (ADR-0008)

У `react-native-keychain` есть незакрытый баг: на части Android-устройств
ранее сохранённый ключ перестаёт расшифровываться
([#802](https://github.com/oblador/react-native-keychain/issues/802)).
Для этого приложения это означает безвозвратную потерю всех документов
пользователя — бэкапа нет по [ADR-0002](../../docs/adr/0002-local-first-storage.md).

Поэтому код здесь обязан:

1. **Сразу после записи ключа прочитать его обратно и сверить.** Если не
   совпало — сказать пользователю сейчас, а не когда он через месяц
   попытается открыть документ.
2. **Не падать при ошибке чтения ключа.** Понятное сообщение вида «не
   удалось получить доступ к зашифрованным данным на этом устройстве»
   вместо краша или молчаливо пустого списка.

Подробности и план пересмотра —
[ADR-0008](../../docs/adr/0008-known-risk-keychain-decryption-failures.md).
