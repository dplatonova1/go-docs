# src/storage

Файловое хранилище документов пользователя.

- Файлы пишутся на диск в зашифрованном виде
  (`@dr.pogodin/react-native-fs`), ключ шифрования — в Keychain/Keystore
  через `react-native-keychain`.
- По умолчанию всё локально на устройстве. Облачная синхронизация —
  только позже и только с client-side (E2E) шифрованием.
- Ключ никогда не покидает устройство и не попадает в БД, логи или
  аналитику.
