# src/features

Фичи по вертикалям, каждая — своей папкой (UI + логика + типы).

Ориентир по фазам из `CLAUDE.md`:

- `checklist` — создание заявки, разбивка вставленного текста на пункты
  (простая эвристика, без ML/NLP), загрузка файлов (Фаза 1).
- `package` — сборка финального PDF-пакета с реестром, детектор
  некачественных фото (Фаза 2).
- `forms` — каталог форм, docx-парсер (legacy form fields), сопоставление
  по структурному fingerprint, заполнение по позиции + подписи перед
  полем. Рантайм строго детерминированный и офлайн: никакого AI и сети
  (Фаза 3). Позже — PDF AcroForm пайплайн за тем же интерфейсом (Фаза 5).
- `profile` — профиль пользователя и MRZ-сканирование паспорта с
  обязательным ручным подтверждением каждого автозаполненного поля
  (Фаза 4).
