# src/navigation

Навигация приложения: навигаторы, типы маршрутов и параметров, deep links.

Библиотека ещё не выбрана — ставится в Фазе 1 вместе с первыми экранами
чек-листа. Ориентир — React Navigation: Expo Router неприменим, проект
не на Expo ([ADR-0001](../../docs/adr/0001-bare-react-native-new-architecture.md)).

## Конвенции

- **Параметры маршрутов типизированы** (`RootStackParamList` и т. п.) —
  никаких `any` в `navigate`.
- **Аппаратная кнопка «назад» на Android обрабатывается явно** на экранах
  с несохранённым состоянием: заполнение формы, съёмка MRZ, сборка пакета.
  Уход с экрана не должен молча терять введённое.
- **Deep links** — только внутренние. Внешних ссылок, открывающих
  приложение с данными, быть не должно.
